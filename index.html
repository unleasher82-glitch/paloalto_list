Paste the steps one at a time into the CLI on the target firewall, waiting for the prompt to return between pastes. Long lists are split into small steps because PAN-OS can reject lines from a very large single paste. Object names are shortened to PAN-OS's 63-character limit automatically. Address inputs and command output are processed locally in your browser.

Data processing & privacy

Address inputs and generated results are processed in your browser. These tools do not submit them to a server or apply changes to a firewall.

The pages contain no application analytics or tracking scripts and load no external fonts. Cloudflare hosts the site and receives normal web requests, including connection information needed to serve the pages.

Copy and download actions happen only when you choose them. Review generated output before using it in configuration.
